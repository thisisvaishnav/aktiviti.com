Quick answer

Aktiviti 1.8 adds the aktiviti command. What the app sees, the apps using your Mac, the ports and dev servers each project holds, your coding agents and what is left of your AI plans, is now an answer in Terminal, as a table you can read or JSON a script can parse. It comes with the app, or with Homebrew in one line. And anyone can now try every feature free for 3 days before buying.

Turn it on

The command is inside Aktiviti, so there is nothing else to download.

  1. 01 Open Settings → Integrations and turn on Let AI Assistants Ask Aktiviti.
  2. 02 Aktiviti puts aktiviti in /opt/homebrew/bin or /usr/local/bin, with its manual page and tab completion, and the Terminal section there says where. If that folder needs your password, Install asks for it once.
  3. 03 Open Terminal and ask.
$ aktiviti version

Or install it with Homebrew

One line installs the app and the command together, with the manual page and tab completion for zsh, bash and fish. Aktiviti updates itself, so brew upgrade leaves it alone.

$ brew install --cask foredotstudio/tap/aktiviti

To remove Aktiviti and everything it keeps, brew uninstall --zap --cask aktiviti.

Ask your Mac

Every answer is the one the window would give: apps with their helpers counted in, projects with their ports, agents with what they started. Each one says when it was measured, and the command measures nothing itself, so asking costs your Mac almost nothing.

$ aktiviti status
$ aktiviti top cpu day
$ aktiviti ports
$ aktiviti agents
$ aktiviti limits
$ aktiviti whats-wrong

aktiviti help lists every command, and man aktiviti explains each one. The whole list is on the command’s page.

For scripts and agents

Add --json to any command and it answers in JSON, the same answer the MCP server gives. --csv gives the main list for a spreadsheet, and --watch keeps the answer fresh every two seconds. In a pipe nothing is cut short, so a script or an agent with a shell reads every word.

$ aktiviti top --json | jq '.apps[0].name'
$ aktiviti ports --csv > ports.csv
$ aktiviti status --watch

Stop what nobody is using

aktiviti can-quit gives a verdict first: safe, ask first, or leave it alone, with the reason and what would stop with it. aktiviti quit and aktiviti stop show that verdict and wait for your yes. What needs a person is refused without a terminal to ask on, even with --yes, so a script or an agent can’t wave it through.

$ aktiviti can-quit --port 3000
$ aktiviti stop --idle

Every quit and stop is written to the log in Settings → Integrations → Requests.

Questions people ask

Is 1.8 a free update?

Yes. In Aktiviti, choose Check for Updates. Everything in it, the command included, is part of every license.

Do I need Homebrew?

No. The command is inside the app: turn on Let AI Assistants Ask Aktiviti in Settings → Integrations and it is on your PATH. Homebrew is only another way to install.

Does Aktiviti have to be running?

Yes. The command asks the running app, which already keeps the readings and the history. If Aktiviti isn’t running, the command says so.

Can an AI agent stop things with it?

Only what Aktiviti judges safe, and only after a yes. Without a terminal to ask on, anything that needs a person is refused, even with --yes.

How long is the trial, and what happens after it?

3 days with every feature. After that, Aktiviti asks for a key; buy a license and paste it, and everything Aktiviti recorded during the trial is still there.

Does reinstalling start the trial again?

No. The trial runs once per Mac.

Where is the list of every command?

On the command’s page, and in Terminal with aktiviti help or man aktiviti.
