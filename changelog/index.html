1.9.0 31 October 2026

The Process Inspector: click any process on your Mac for its code signature, entitlements, parent process, launch agent, full command line, and everything it has used since it started.

How to use what’s new in 1.9.0

  • New Process Inspector. Activity Monitor gives a process a name and a number. Click any process in Aktiviti and its drawer tells you the rest: the app it belongs to, its code signature and Team ID, hardened runtime, sandbox and entitlements, its parent process and launch agent, its full command line and environment, its open files, listening ports and child processes. Click a parent or a child to follow it.
  • New A process’s whole life, not just this second. CPU time since it started, split into user and system, memory now against its peak, threads, page-ins and bytes read and written, with a live chart of its CPU and memory while the drawer is open.
  • New A Details card for every app. An app’s drawer now shows its version, bundle ID, architecture, code signature, protection, what starts it, how long it has run and where it is installed, with the whole Info.plist one click away.
  • New What just started, and what just ended. Click any process in an app’s drawer to open its details. One that started seconds ago carries a New mark, and Ended Recently keeps what ended in the last ten minutes, with how long it ran, so a helper that crashed is still there to see.
  • New Copy it, or save it as CSV. Any drawer can be copied as text for a bug report or saved as a CSV file in Downloads, with the Info.plist, entitlements, environment and processes included.
  • New The same in Terminal and for AI assistants. aktiviti process gives the same details by name or PID, as text or with --json. --env adds the environment and --plist the Info.plist. Claude, Codex and Cursor get them through the process_details tool, without the environment, since it can hold keys.
  • New The apps behind a spike. aktiviti top --at 14:02 or --from 14:00 --to 15:30 tells you which apps used the most at that time, and an assistant reading your history sees the apps beside each peak.
  • Improved Five new columns. PID, User, Start Time, Version and Path can join the app table, from a new Columns menu in the toolbar.
  • Improved Regular expressions in the filter. Type a pattern between slashes, such as /helper|agent/.
