Why it matters

GPU and Neural Engine, before and after

Activity Monitor gives the GPU a column, % GPU, and a GPU History window, and gives the Neural Engine nothing. On Apple silicon the Neural Engine does real work, for Photos, Spotlight, dictation and on-device models, and there has been no way to see when, or for which app.

Meanwhile the GPU is where local models actually run. PyTorch and MLX use the GPU, not the Neural Engine, so an Ollama session shows up as a busy GPU and a quiet Neural Engine, which is correct and surprising.

Aktiviti gives each its own tab: how busy it is, the GPU's memory, the average and the peak, the apps using it heaviest first, and a chart of the last 5, 15 or 30 minutes. The Neural Engine's number is worked out from the memory it moves against the most this Mac has moved, and the apps that hold it open are named. Both can be menu bar items and Overview cards, and Aktiviti tells you when an app has kept the Neural Engine busy for twenty minutes.

The words behind it

What the numbers mean, from the Activity Monitor glossary.

  • % GPU

    % GPU is the share of the graphics processor's capacity that a process is using.
  • Unified memory

    Unified memory is the single pool of RAM in an Apple silicon Mac, shared by the CPU, the GPU and the Neural Engine.
  • MTLCompilerService

    MTLCompilerService is the macOS process that prepares graphics code for the GPU on behalf of apps that use Metal, Apple's graphics framework.
  • Performance and efficiency cores

    Performance and efficiency cores are the two kinds of CPU core in Apple silicon Macs.

Questions

The ones people ask about GPU and Neural Engine before they buy.

Does Aktiviti show Neural Engine usage?

Yes, on Macs with Apple silicon: how hard it is working, which apps are using it, and a chart of the last minutes, in the window, the menu bar and on the Overview.

Why does my local model not show on the Neural Engine?

Models run with PyTorch or MLX use the GPU, not the Neural Engine. They show on the GPU tab.

Does it show GPU memory?

Yes, with the GPU's use, average and peak, and the apps using it.

Does Activity Monitor show this?

Activity Monitor has a GPU column and a GPU History window, and nothing for the Neural Engine.

How does Aktiviti measure the Neural Engine?

From the memory it moves, against the most this Mac has ever moved. macOS does not say which app is working it, only which apps hold it open, and those are what Aktiviti names.

Which Macs have the Neural Engine tab?

Macs with Apple silicon. On an Intel Mac there is no Neural Engine, and no tab.

Why is the GPU busy when I run Ollama?

Because models run with PyTorch or MLX use the GPU, not the Neural Engine. They show on the GPU tab, and Ollama's memory shows under Ollama.

Does it show the GPU's temperature?

Yes, with the other sensors, and the fans if the GPU is what is driving them.
