Why it matters

MCP server, before and after

Ask an assistant why your Mac is slow and it runs ps aux, gets a thousand lines, and guesses. It sees node at 180% and cannot tell which project, which chat, or whether that is the test run you started on purpose. It sees a port in use and offers to kill whatever holds it.

Assistants are good at the next step, what to do about it. What they lack is the picture Aktiviti already has: apps with their helpers added up, projects with their ports, sessions with what they started, and what the last month looked like.

Aktiviti is an MCP server. Claude, Claude Code, Codex, Cursor and any assistant that speaks MCP can ask it what is running and get the same numbers you see, each with when it was measured. When an assistant wants something quit, it has to ask Aktiviti, and Aktiviti asks you, in a window of its own, with what is connected to it right now. You decide what it may see: system readings, apps, projects and history each have a switch, and project folders can go by name only.

How to use it

Where it is in Aktiviti

The tab, the menu bar item and the setting, in the order you would reach for them.

  1. 01

    Turn it on

    Settings → Integrations lists Claude, Claude Code, Codex and Cursor with an Add button each. Add puts Aktiviti in the assistant's own list of tools; an assistant that is open sees it when it next starts. Any other assistant that speaks MCP takes the command shown there.

  2. 02

    Choose what it may see

    Switch off system readings, apps, projects or history for every assistant at once, and give project folders by name only, so an assistant hears "shop" and not where that folder lives on your Mac.

  3. 03

    Ask

    What is eating my memory. What is on port 8080. Which coding sessions are running, and which chat is each. How hard was the Mac pushed this week, and when was it at a limit. Every answer says when it was measured.

  4. 04

    When it wants to quit something

    The request comes to you in a window of its own: what is asking, what it wants to quit, whether that looks safe, and what is connected to it right now. Nothing closes until you say so. For a project folder you trust, add it in Settings → Integrations and safe requests there go through without asking.

The words behind it

What the numbers mean, from the Activity Monitor glossary.

  • Listening port

    A listening port is a network port where a process is waiting for incoming connections, such as a web server on port 3000.
  • PID

    A PID, or process ID, is a number macOS assigns to each running process to identify it.
  • Force Quit

    Force Quit ends an app or process immediately, without letting it save or clean up.
  • Helper processes

    Helper processes are separate processes an app starts to do part of its work, such as rendering web pages, running extensions, or handling graphics.

Questions

The ones people ask about MCP server before they buy.

Which assistants work with it?

Claude, Claude Code, Codex, Cursor and any assistant that speaks MCP. Settings → Integrations adds the first four with one button each; any other takes the command shown there.

Can an assistant quit apps through Aktiviti?

Only through you. It asks Aktiviti, Aktiviti shows you what it wants to quit in a window of its own, and nothing closes until you say so. If you say no, it stays running.

Does it send my data to the assistant's maker?

Aktiviti answers the assistant on your Mac and sends nothing anywhere itself. What the assistant does with the answer is up to the assistant, the same as anything else you tell it.

Is it on by default?

No. It stays off until you turn it on in Settings → Integrations.

What can I stop an assistant from seeing?

System readings, apps, projects and history each have a switch in Settings → Integrations, for every assistant at once. Project folders can be given by name only.

Can safe requests go through without asking me?

Yes, for folders you choose. Add a project folder, or a folder that holds your projects, in Settings → Integrations, and what Aktiviti judges safe there is quit without asking. Everything else is still asked about.

How do I know what else will stop working?

Before anything is quit, the window names what is connected to it right now, such as Google Chrome or a process in another project, so you can see what else would break.

Can my assistant ask about last week?

Yes. It can ask how hard your Mac was pushed over a day, a week or a year, when it was at a limit, and which apps used the most over 90 days, 6 months or a year.

Can an assistant on another computer ask my Mac?

Yes, over SSH. Point the assistant's MCP config at ssh that-mac "~/Library/Application\ Support/Aktiviti/aktiviti" mcp: the server runs on the Mac that has Aktiviti, and the assistant on your PC or laptop gets the same answers. Aktiviti has to be running there, in the account you log in as, with Remote Login on.
