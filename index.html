Common Questions

Frequently Asked Questions

Everything you need to know about Aktiviti, compatibility, licenses, and privacy.

How does Aktiviti differ from macOS Activity Monitor? +
Activity Monitor lists every individual Unix PID—often 1,000+ rows on a working Mac, where 50+ entries are just "Google Chrome Helper". Aktiviti consolidates helpers directly under the parent application so each app has one clean row for CPU, memory, GPU, disk, and network. In addition, Aktiviti records up to 1 year of history, inspects developer code signatures and sandboxing, monitors coding agents, and exposes an MCP server for Claude and Cursor.
Which Macs and macOS versions are supported? +
Aktiviti is built natively for macOS 14 Sonoma and macOS 15 Sequoia (and later). It runs natively on all Apple Silicon Macs (M1, M2, M3, M4, Pro, Max, and Ultra) as well as Intel-based Macs. GPU core and power readings are most detailed on Apple Silicon.
Does Aktiviti cause high CPU usage or slow down my Mac? +
No. Aktiviti is written in lean, native Swift and C, utilizing low-overhead Mach kernel APIs (`host_processor_info`, `mach_vm`) and IOKit. When the dashboard window is closed, background sampling happens only once every 5 seconds and uses less than 0.1% of one CPU core.
How does the MCP server work with AI tools like Claude & Cursor? +
Aktiviti includes a lightweight Model Context Protocol (MCP) server. When added to your Claude Desktop config or Cursor settings, your AI assistant can directly query your Mac's current metrics. You can ask: "Which Node servers are running on port 3000?", "Why is my Mac heating up?", or "Check if any process is leaking memory".
What happens after 1 year on the Standard plan? +
Nothing stops working. Your license is perpetual. The version you have will continue working indefinitely. If you wish to receive updates released after your 1-year window has closed, you can renew at a discounted rate, or choose Lifetime to never worry about renewals.
Can I move my license to a new Mac? +
Yes! You can deactivate a license on an old Mac and activate it on your new Mac at any time without having to email support or create an online account.
